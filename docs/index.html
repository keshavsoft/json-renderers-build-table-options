json-renderers-build-table-options

Declarative table decorator providing serial numbers (#), action options, and search extensions to JSON table specifications.

Version 3.0 DOM-free Declarative Instructions

Feature Overview

  • showSerial: Automatically inserts serial numbers (#) into colgroup, thead, and each tbody row.
  • showOptions: Injects an action options column with configurable buttons.
  • v3 Input Guard: Strictly verifies parameter types and ensures inBase is an object to prevent silent errors.

Quick Usage

import buildOptions from "json-renderers-build-table-options";

const outputSpec = buildOptions({
  inOptions: {
    showSerial: true,
    showOptions: true
  },
  inBase: tableJsonSpec
});
